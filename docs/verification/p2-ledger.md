# P2-05 与 P2-06 财务本地验收

2026-11-07 在现有本地 Aspire 环境及 PostgreSQL 数据卷通过。Finance 和 Organization 增量迁移已应用，两套 EF 模型均无待生成的迁移。

## 使用入口

1. 初始化企业账簿。在公司侧栏打开「团队与成员」，找到成员后点「编辑权限」。一位所有者提交财务角色申请，另一位所有者批准。制单人取得「财务制单」，复核人取得「财务复核与期间管理」。每个成员同时只持有一个财务执行角色。
2. 复核人在「账簿设置 → 会计期间、期初与凭证」开放月份。制单人可保存和提交期初单及手工凭证。期初单使用核算起点日期和资产、负债、权益科目，并在首笔普通凭证过账前完成。
3. 复核人按提交版本确认过账。制单人可发起关联冲销，另一位具有复核权限的成员批准后过账。冲销使用原凭证的科目和金额快照生成反向分录，原凭证保留原样。
4. 关账先进入 Closing 并固定水位，再核对待处理凭证与借贷合计。关闭、重开均记录操作者、期间版本和原因。

科目替换从首张凭证草稿产生时停止。凭证、期间和科目写入共用同一账簿事务锁。来源编号和操作编号分别防止业务单据重复入账及同一请求重复执行。账簿金额在 HTTP 接口和页面之间使用十进制字符串。

## 本地验证范围

| 场景 | 验收标准 |
| --- | --- |
| 期初对账 | 现金借方 1,000.00，期初权益贷方 1,000.00。期初重复、损益科目、不平衡及超币种精度均被拒绝。 |
| 范围与职责 | 两个 OIDC/TOTP 会话分别制单和复核。测试同一账号申请并批准授权、切换角色后自行过账、跨工作区读取、引用其他账簿科目，以及无权限重开。 |
| 期间门禁 | 并发提交过账和开始关账。水位包含关账前成功的过账，Closing 期间拒绝后续过账。存在待处理凭证时拒绝确认关闭。 |
| 导入失败与历史 | 含无效行的文件无法生成可提交预览。过时预览和开始核算后的 Replace 提交均被拒绝，科目内容和版本保持原样。导入预览绑定操作者。科目归档后，历史凭证仍保留原科目快照。 |
| 来源幂等与冲销 | 同一来源编号不能重复建立凭证。操作重试返回原结果。冲销完成后，现金期初净额仍为 1,000.00，原交易收入净额回到 0.00，可按科目钻取全部已过账凭证。 |
