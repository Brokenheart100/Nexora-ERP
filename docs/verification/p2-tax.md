# P2-04 税组与税额快照本地验收

2026-11-07 在 Aspire 本地栈验证，Finance 通过 HTTP 读取同工作区的 MasterData 商品和往来单位版本。工作区所有者在账簿设置维护税项、税组和分类。

- 税率版本按业务日期生效，同一税项及生效日期只允许保存一次。税组与分类保存版本，税额快照保存实际应用的税组、税率、生效日期、主数据版本、币种与舍入规则。
- 选择顺序为显式税组、往来单位默认税组、商品默认税组。各税项按同一行基础金额计算，可叠加。含税结果按本位币精度调整尾差，保证未税和税额之和等于舍入后的含税金额。
- 页面用十进制字符串传入税率和金额，按快照 ID 查询历史值及税项明细。
- Playwright 通过真实登录、CSRF 和 BFF 验证创建税率及税组、两类主数据引用、无效 ID、重复提交、跨工作区拒绝和历史快照。C01 的未税结果为 270.00 + 35.10 = 305.10，含税 113.00 拆分为 100.00 + 13.00。新增后续税率后，历史快照保持原值。[样例口径](../domain/p0-policies.md#c01--税额拆分与舍入)
- 本地使用测试配置。真实税务模板与交易单据集成分别在业务验收及后续阶段继续跟踪。
