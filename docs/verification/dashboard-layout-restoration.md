# Dashboard 原有界面与真实数据接入

> 2026-11-20 状态更新：替代 UI 已按用户要求删除。本记录为当时版本的历史验证；当前保留 BFF / 客户端 / MSW 基础，原界面接入状态见 [删除记录](dashboard-replacement-ui-removal.md)。

2026-11-20，已完成本地验证。

## 原因

原有 `app/pages/`、Carbon 主题、工作台和业务界面仍在。此前接入 D1–D4 时，`app.vue` 对真实及 MSW 模式直接渲染了另一个简化的 `LiveDashboardLayout`，绕开原来的 `MockDashboardLayout`。这不符合接入计划中“两种模式共用布局”的要求。之前的 API 及业务流程验收不能替代界面保持验收。

## 本轮设计约定

- 复用原有侧栏、工作区入口、全局搜索、语言及用户区、可折叠宽度、页头和 Carbon 主题。
- 把原布局提取成数据无关的公共展示组件，模拟原型与真实 / MSW 接入共同使用；各模式分别提供自身的导航、工作区和用户数据。
- 真实导航和搜索只使用当前工作区已授权且具备权益的页面。原型中的演示身份、演示通知和模拟治理写入留在纯界面预览。
- 工作台恢复原有页头、卡片网格和分栏结构；未接入的经营统计明确显示待接入，不将原型数值放进真实模式。
- 已有 D3、D4 的版本、幂等、未知结果、权限与业务流程继续使用当前 API 客户端。
- 桌面与手机布局、真实 / MSW 同一外观、原型入口及已接入操作都通过浏览器复验。

## 实现

原来的布局模板提取为 [`DashboardShell`](../../src/Web/nexora-dashboard/app/components/DashboardShell.vue)，负责同一套可折叠侧栏、页头外框、搜索、语言及用户插槽。`MockDashboardLayout` 保留原来的导航、演示工作区、搜索数据和原型抽屉；`LiveDashboardLayout` 注入真实或 MSW 的身份、工作区及授权页面。原有 15 个文件路由页面全部保留，工作台原型内容与 D4 开始前的快照一致。

真实模式通过相同的 Nuxt UI DashboardPanel / DashboardNavbar 展示已接入内容，工作台恢复原有六张卡片与分栏结构。统计尚未接入时显示 `—` 和状态提示。原型治理、演示身份和模拟通知不会混入真实模式。真实模式还提供语言、主题切换及实际注销。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 布局回归先红后绿 | 原简化布局缺少侧栏，新增 MSW 回归失败；共用布局后通过 |

| lint / strict typecheck | 通过 |
| mock / live Node 构建 | 均通过 |

本机截图为 `artifacts/p1/runtime/layout-restored-live.png`、`layout-preserved-prototype.png` 和 `layout-restored-msw.png`。去敏统计与当前源码指纹见 [results.json](../../artifacts/dashboard-layout-restoration/results.json)。

## 复查与范围

正确性复查覆盖页面可见性、工作区切换、未知结果与版本冲突既有流程。展示组件与数据容器分离，真实搜索仅含获准页面；真实界面使用真实身份且不显示演示身份切换。业务请求与服务端权限逻辑不变，没有增加无界数据读取或页面统计猜算。

本轮临时启动的 AppHost 已正常停止，四个命名持久卷保留。未修改后端服务、数据库模型、依赖版本或原型页面内容；本地 UI 和业务专项通过不代表远程 CI 或生产验收。
