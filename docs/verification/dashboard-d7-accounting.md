# Dashboard D7 期初、总账与关账验收

2026-11-21，在原 `nexora-dashboard` 的财务页签验证。Playwright 创建独立测试工作区，Alice 以会计身份制单，Bob 独立复核，服务通过真实 Nitro BFF 调用。

## 界面入口

- 「财务工作台」初始化账簿。「科目表」维护科目，并提供模板、结构、快照下载及版本绑定的导入预览和提交。
- 「期初导入」可分别预览总账期初凭证和期初子账 CSV。期初子账详情显示库存回执、对账结果和来源凭证。
- 「凭证」查看草稿、复核、冲销、关联和试算平衡。「外部凭证」登记导入来源编号，选择至多 50 张提交、取消或独立过账。
- 「关账与年结」查看待计价与过账水位，处理成本补记、月结和重开。此处还可配置合伙分摊并预览年结。

## 真实 AppHost

| 场景 | 结果 |
| --- | --- |
| 账簿和科目导入 | 从财务工作台初始化账簿，验证空账替换。新增并归档科目，下载模板、结构及快照。重复编码预览禁止提交，并行变更使先前预览失效，重新预览后导入成功。总账期初入账后，服务拒绝改变在用科目的用途及替换科目表。 |
| 总账与子账期初 | 总账期初独立过账。一个批次导入库存 2 件、成本 20 元，应收 65 元、应付 41 元和银行 100 元。科目修订使旧预览失效，创建人不能复核，重复提交冲突。复核先进入 `applyingstock`，库存确认后批次过账，四行对账一致，生成四张凭证。批次可回查银行期初流水。 |
| 手工凭证与冲销 | 原页新增及编辑草稿、提交与独立过账。制单人发起冲销，另一人独立过账，可回查原凭证。查看期末试算平衡。 |
| 外部凭证与关联 | 同一请求键回读原结果，新请求使用相同来源编号收到 409。批次含过期版本时整批保持原状态，刷新后批量提交并独立过账。新增、移除和扫描凭证关联。 |
| 月结与重开 | 会计期间可开启、开始关账、关闭和重开。关账中仍有待独立复核凭证时，服务拒绝完成关账。 |
| 就绪、年结与合伙 | 回读待计价并执行补记命令。通过界面保存两位合伙人 60% 与 40% 的份额，预览列出未关账月份。十二个月关闭后，制单人提交，另一人复核结转，产生两张凭证。重开财年记录原因并生成两张冲销凭证。 |

## MSW 与构建

3 项 MSW 浏览器用例覆盖科目预览过期后重新导入、库存回执延迟时阻断科目修改、回执后显示一致结果或对账差异，以及从扫描结果回查凭证。TypeScript 检查、169 项前端单测和真实模式生产构建通过。构建输出保留 Vite 的单块体积提示。
