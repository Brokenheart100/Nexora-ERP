# ADR 0016 — 银行、周期、通信、捐赠及平台扩展

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

补齐核心进销存外的参考能力仍需明确事实归属。

## 决策

Treasury 管银行 / 对账；AR 管周期计划 / occurrence / PDF / Dispatch；Donations 管捐赠事实 / 收据；Organization 管个人链接 / 订阅 / 能力与平台记录；Gateway 管受限 CLI / AI / MCP 接入。

PDF 采用服务端受控渲染端口；P0 优先验证 Playwright / Chromium 与固定中文字体。Windows 技术探针已通过，生产引擎启用仍须镜像 / 模板与资源隔离验收。PDFsharp 6.5 许可及运行探针失败已记录，不自动以 AGPL 设置或降级停更版本绕过。

## 比较与取舍

不为每个界面建服务，不把外部 provider 回跳当成付款事实，不让模型跨库直接修改财务。

## 影响与约束

邮件未知结果、计费乱序、链接 / 收据撤销、AI 写工具审批与来源幂等均须保留；法定票据资格单独验证。

## 验证与未决条件

- 验证：银行导入去重、对账撤销、重复周期触发、邮件回执丢失、收据更正与工具越权。
- 未决 / 后续条件：PDF 的 Linux / 生产模板 / 打印、邮件 / billing / agent 渠道及中国大陆法定输出验证仍未完成。
