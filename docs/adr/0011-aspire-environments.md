# ADR 0011 — Aspire 编排与环境边界

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

工作区已有空 AppHost，应从现状演进而不是重新初始化。

## 决策

沿用 Aspire / net10.0 的现有配置，按阶段加入资源、独立数据库、引用和健康检查。ServiceDefaults 属于技术宿主。当前 Aspire 版本见 [依赖基线](../依赖.md#3-当前工程依赖声明)。

## 比较与取舍

不安装旧 workload，不把本地启动、单机 Compose 或容器卷当成生产高可用 / 备份。

## 影响与约束

生产网络、秘密、持久存储、身份配置、备份和监控需要目标环境配置。

## 验证与未决条件

- 验证：P1 编排与链路实测；P6 验证目标部署、恢复和资源边界。
- 未决 / 后续条件：本次 P0 不修改或启动 AppHost；后续改资源需按项目 Aspire 技能执行。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
