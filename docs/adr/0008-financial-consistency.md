# ADR 0008 — 过账、核销、税务模板与期间门禁

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

财务局部不变量不能仅靠跨模块异步事件保证。

## 决策

Finance 同库维护来源开票额度、未结项 / 核销、Journal 与 FiscalPeriod；显式锁顺序和版本。Closing 先封普通入口，排空水位后在门禁下复核检查版本。税务模板独立版本化。

## 比较与取舍

不直接编辑已过账记录，不用异步余额投影校验核销，不以某一示例税率覆盖所有交易。

## 影响与约束

少量同上下文跨聚合事务列为明确例外；自动凭证限制统驭科目手工直记。

## 验证与未决条件

- 验证：C01 / C03 / C04 样例、并发核销、重复来源、关账并发和迟到事实处理。
- 未决 / 后续条件：真实纳税人类型、税目适用 / 收据资格待确认，P0-03 不因此虚假完成。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
