# ADR 0005 — RabbitMQ、Wolverine 与幂等

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

必须覆盖本地提交、发布结果未知、消费恢复和重复投递。

## 决策

各服务同库配置 Wolverine PostgreSQL 消息 schema，发送 / 接收端显式 durable，业务写 / 审计 / Outbox 共事务。框架信封与业务来源分层幂等，跨服务不用分布式事务。

## 比较与取舍

不手写通用交付 / 租约框架；不承诺全局恰好一次，也不把 broker ack 等同业务成功。

## 影响与约束

独立监控 broker DLX、框架错误存储、积压与恢复；操作级重投必须审计。

## 验证与未决条件

- 验证：接收落库、业务提交、broker 确认三个边界的崩溃 / 重放测试。
- 未决 / 后续条件：序列化和消息表迁移必须兼容滚动部署；保留期按恢复窗口确定。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
