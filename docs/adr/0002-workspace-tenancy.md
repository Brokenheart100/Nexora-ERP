# ADR 0002 — 租户、工作区与账簿隔离

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

用户确认首个验证账簿为中国大陆 / CNY，同时需要企业与个人账本。

## 决策

Tenant 是安全 / 订阅边界，CompanyId 是核算工作区。企业与个人类型各自账簿 / 本位币，身份按 issuer + subject 关联；所有业务唯一键、缓存、消息与后台任务显式携带范围。

## 比较与取舍

采用共 PostgreSQL 实例、独立服务数据库起步；不使用共享业务 DbContext 或仅靠前端工作区选择。

## 影响与约束

EF 过滤之外还要验证原生 SQL、保存拦截、外键归属、文件、消息和后台上下文。

## 验证与未决条件

- 验证：跨工作区 ID / 缓存 / 文件 / 消息攻击、个人链接解除与期初隔离测试。
- 未决 / 后续条件：大租户分库保留为路由演进；不在领域对象存数据库位置。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
