# ADR 0007 — 库存维度与移动加权计价

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

首期商贸库存需要数量、价值及总账三方可追溯。

## 决策

工作区 + 仓库 + SKU 成本池，移动加权平均，禁止负库存；数量事实产生同池序列，计价按序处理，保留成本版本。调拨按源出库成本入目标，保留在途。

## 比较与取舍

不同时实现 FIFO / 多计价法，不以当前商品成本覆盖历史，不为缺失成本自动入零。

## 影响与约束

批次 / 序列号 / 复杂换算后续扩展需改变库存维度和计价协议。

## 验证与未决条件

- 验证：C02 库存算例、成本缺口、收发并发、退货原成本、价差及总账对账。
- 未决 / 后续条件：真实价差容差、库存政策由工作区确认；当前研发默认见政策台账。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
