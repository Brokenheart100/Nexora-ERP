# ADR 0015 — AccountGo 固定功能基线与验收

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

功能对齐应可追溯到固定版本和用户结果。

## 决策

以 535c1cd 的 F01–F42 与 S01–S17 为基线，区分 README 声明、源码入口和外部 / 可选能力；每功能有 UC、页面、API、授权、异常和验收。

## 比较与取舍

不按 UI 页面或框架包数量宣称对齐，不把 unavailable / 模拟成功记作启用能力已完成。

## 影响与约束

当前所有 F 项保持未完成，新增差异更新证据与用例，不静默删功能。

## 验证与未决条件

- 验证：validate_p0.py 检查 F / UC / TODO 覆盖与文档链接；业务与联调验收留至各阶段。
- 未决 / 后续条件：基线后续升级须新增差异记录，不自动跟随 main。
- 政策和样例：[P0 政策](../domain/p0-policies.md)；领域与契约：[上下文及状态机](../domain/p0-contexts-contracts.md)。
- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
