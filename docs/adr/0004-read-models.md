# ADR 0004 — CQRS 与投影重建

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

需要任务式交易 UI、跨域经营报表与可复核账簿。

## 决策

首期逻辑 CQRS，同服务读写可共库；跨域 Reporting 消费事实，正式财务数来自 Finance。快照导出带水位 / 校验，接续增量并双算校对后切换。

## 比较与取舍

不要求 Event Sourcing，也不把 RabbitMQ 或短期 Outbox 当成永久可重放事实库。

## 影响与约束

投影可延迟，界面和导出显示口径 / 水位；额度判断只能走事实所有者。

## 验证与未决条件

- 验证：投影落后、重复 / 乱序、从快照重建时不漏不重以及报表 / 正式账簿对账。
- 未决 / 后续条件：数据量或查询证据支持后再引入独立读副本 / 专门分析存储。

- 核心依赖接入情况：[可行性记录](../domain/p0-feasibility.md)。
