# ADR 0012 — 迁移、切账、恢复与验收目标

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

独立数据库和异步流程要求业务可恢复而不只是容器可启动。

## 决策

每服务独立迁移任务，expand / 兼容 / 回填 / contract；期初导入有批次与对账。恢复先身份和事实，再补投 / 对账，最后开放写入并重建投影。

## 比较与取舍

不让多副本启动争抢迁移，不自动执行破坏性降级，不将容器卷视为备份。

## 影响与约束

初始容量 / P95、RPO 15 分钟与 RTO 4 小时是待验证目标，非当前承诺。

## 验证与未决条件

- 验证：备份恢复、跨时点库差异、消息补投、旧镜像回退、附件与密钥恢复。
- 未决 / 后续条件：生产预算、备份存储与容量参数待环境确定。
