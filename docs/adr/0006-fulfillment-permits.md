# ADR 0006 — 订单许可、预留及取消栅栏

- 日期：2026-11-06
- 状态：已采纳为技术设计基线；实现和业务条件按验证项继续跟踪。
- 关联：[架构](../架构.md)、[计划](../计划.md)、[依赖](../依赖.md)。

## 背景

异步订单投影不能防止并发超收 / 超发。

## 决策

订单所有者在聚合内原子占用许可额度，Inventory 幂等执行，结果回执更新源流程。取消先由执行方持久化终态栅栏，再释放未执行量；已执行事实走退货 / 更正。

## 比较与取舍

不采用先查投影剩余量再提交，也不将超时直接当失败释放额度。

## 影响与约束

多行预留可能部分成功，首期整次申请全部预留后才可发货；失败释放也需持久化追踪。

## 验证与未决条件

- 验证：并发许可、发货 / 过期竞争、取消回执先到 / 原消息晚到和部分执行取消。
- 未决 / 后续条件：后续支持超额容差或部分承诺策略须显式版本化政策。
